# TTS 方案分级（按硬件自动选）

**实测数据（2026-11-18，同一句话 20 字）：**

| 方案 | 耗时 | 相对 | 音质 | 需要什么 |
|---|---|---|---|---|
| **A. 本地 GPU** | **3.9 秒** | 1x | ★★★★★ 自己的音色 | Vulkan/CUDA 显卡 + 8GB 显存 |
| **B. 本地 CPU** | **187.8 秒** | **48x** | ★★★★★ 自己的音色 | 只需 CPU，但 39 句要 8 小时 |
| **C. 在线 API** | ~3 秒 | ~1x | ★★★★ | 网络 + API Key |
| **D. edge-tts** | ~1 秒 | **0.25x** | ★★★ 通用声音 | 网络，免费无 Key |

---

## 检测逻辑

```
开始
 │
 ├─ ① 有 Vulkan/CUDA 显卡且显存 ≥6GB？
 │     └─ 是 → A. 本地 GPU（推荐，音色可克隆）
 │
 ├─ ② 有 API Key（阿里云 DashScope / 火山 / MiniMax）？
 │     └─ 是 → C. 在线 API（音色可克隆，但要付费）
 │
 ├─ ③ CPU 核数 ≥8 且愿意等？
 │     └─ 是 → B. 本地 CPU（1 条约 8 小时，可挂机）
 │
 └─ ④ 都不满足 → D. edge-tts（免费，通用音色）
```

**为什么 A 排第一：** GPU 3.9 秒 vs CPU 187.8 秒，48 倍差距。而且只有本地模型能完全克隆音色。

**为什么 D 是兜底：** edge-tts 免费、无需 Key、1 秒一句。**缺点是不能克隆音色**，只能用微软的通用中文声音（云希、晓晓等）。

---

## 各方案细节

### A. 本地 GPU（最优）

```
需要：
· Vulkan 1.2+ 或 CUDA 11.8+ 显卡
· 显存 ≥6GB（q8 模型 2.1GB + 推理开销）
· 内存 ≥16GB
· 磁盘 3GB（q8）或 8GB（f32）

实测：独显 16GB → 3.9 秒/句
预计：中端独显 12GB → 4-6 秒/句
      低端独显 4GB → 可能不够，需降级

检测命令：
  audiocpp_cli.exe --list-devices
  → 看到 Vulkan:0 [GPU] 才算
```

**降级判断：如果只有 `Vulkan:1 [IGPU]`（核显），实际速度和 CPU 差不多，应该直接选 B 或 D。**

### B. 本地 CPU（能跑但慢）

```
需要：
· CPU ≥8 核（16 线程更好）
· 内存 ≥16GB
· 磁盘 2.1GB（q8 模型）

实测：8 核 16 线程 CPU → 187.8 秒/句
推算：6 核 12 线程 → 约 250 秒/句
      39 句 × 4 轮 = 4.3 小时

⚠️ 但实际不会跑 4 轮：脚本会先跑 1 轮，检查吻合度
   如果 1 轮就对，39 句 × 3 分钟 = 2 小时
```

**适合：挂机过夜、只需要一条片子、音色必须是自己。**

### C. 在线 API（音色可克隆）

**可选服务（都支持中文音色克隆）：**

| 服务 | 价格 | 延迟 | 音色克隆 |
|---|---|---|---|
| **阿里云 DashScope（CosyVoice）** | 约 ¥2/万字符 | 快 | ✅ 有 |
| **火山引擎（豆包语音）** | 有免费额度 | 快 | ✅ 有 |
| **MiniMax（海螺）** | 有免费额度 | 快 | ✅ 有 |
| **Azure 语音** | 约 $16/百万字符 | 快 | ⚠️ 需审批 |

**但要注意：** 在线服务的音色克隆通常需要**单独上传授权**，不能直接用本地 ref.wav。

**所以 C 的定位是：有 Key 但没显卡的人，用服务商提供的预置音色。**

### D. edge-tts（兜底）

```bash
pip install edge-tts
edge-tts --voice zh-CN-YunxiNeural --text "文本" --write-media out.mp3
```

**中文音色可选：**

| voice | 性别 | 风格 |
|---|---|---|
| `zh-CN-YunxiNeural` | 男 | 年轻、口语化（最接近口播）|
| `zh-CN-YunjianNeural` | 男 | 成熟、解说 |
| `zh-CN-XiaoxiaoNeural` | 女 | 温柔 |
| `zh-CN-XiaoyiNeural` | 女 | 活泼 |

**优点：**
- 完全免费，无需注册
- 1 秒一句话
- 音质稳定（微软神经网络 TTS）
- **语速可调** `--rate=+10%`

**缺点：**
- **不能克隆音色**（这是最大的损失）
- 不能控制音色细节
- 需要网络

## 音色克隆对成品的影响

**这是用户最该知道的：**

| 方案 | 能否用自己的声音 | 对最终视频的影响 |
|---|---|---|
| A / B | ✅ 可以 | 有个人辨识度，观众记得住 |
| C | ⚠️ 要用服务商的克隆 | 取决于服务商 |
| **D** | ❌ 不能 | **声音是通用的，但其他一切（卡字、画面、节奏）完全一样** |

**关键：卡字率、画面、节奏、字幕这些核心技术指标，跟用哪个 TTS 完全无关。**

**所以 D 方案做出来的片子，除了声音不是本人，其余和 A 方案一模一样。**

## 检测脚本要做的事

```python
def detect_tts_plan():
    """返回推荐的 TTS 方案"""
    
    # ① 有没有好显卡
    gpu = check_vulkan_gpu()
    if gpu.has_discrete and gpu.vram_gb >= 6:
        return "local-gpu"
    
    # ② 有没有 API Key（看环境变量或配置文件）
    if os.environ.get("DASHSCOPE_API_KEY") or config.get("tts_api_key"):
        return "cloud-api"
    
    # ③ CPU 够不够
    cpu = check_cpu()
    if cpu.cores >= 8 and cpu.ram_gb >= 16:
        user_wants_slow = ask("本地 CPU 配音约 2-8 小时，可以挂机等吗？[y/N]")
        if user_wants_slow:
            return "local-cpu"
    
    # ④ 兜底
    return "edge-tts"
```

**必须做的一件事：把检测结果和预计耗时明确告诉用户。**

```
检测结果：
  显卡：独显（Vulkan, 16GB）✓
  内存：31 GB ✓
  
推荐方案：A. 本地 GPU
  预计：39 句 × 4 轮 ≈ 10 分钟
  可以克隆你自己的声音
  
[1] 用这个方案
[2] 我改用在线 API
[3] 我用 edge-tts（免费但音色通用）
```

## 下载体积对比

| 方案 | 需要的下载 |
|---|---|
| A. 本地 GPU | 引擎 84MB + q8 模型 2.1GB = **2.2 GB** |
| B. 本地 CPU | 同上 **2.2 GB** |
| C. 在线 API | 只要 Python 包 **~50 MB** |
| D. edge-tts | 只要 Python 包 **~5 MB** |

**这就是为什么要分级：没显卡的人不该被 2.2GB 的下载体量挡在门外。**
